# 10° Simposium Inmobiliario CANACO CDMX 2026

Landing page estática y responsive para el evento del 29 de octubre de 2026.

## Vista local

1. Descarga el repositorio.
2. Descomprime el archivo ZIP.
3. Abre `index.html` en el navegador.

No requiere instalación, compilación ni dependencias externas.

## Estructura

- `index.html`: estructura y contenido.
- `css/styles.css`: diseño responsive.
- `js/main.js`: menú, contador, avisos y animaciones.
- `images/`: identidad visual, hero y galería.
- `fonts/`: Montserrat y Source Sans 3 con licencia OFL.

## Enlaces pendientes

Los tres botones de acceso muestran un aviso provisional. Cuando existan las ligas definitivas, sustituye `data-pending` por un enlace `href`.

## Personalización

La paleta principal se encuentra en las variables CSS al inicio de `css/styles.css`.
